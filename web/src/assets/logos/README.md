# Official product logos

Drop official Microsoft SVGs here using the file names declared in `src/data/assets.ts`.
They are picked up automatically at build time - no configuration needed.

Nothing in this folder is generated, redrawn or approximated. See the project
README section 'Product assets' for sources and terms.

## Header brand marks

Add these two files to replace the neutral placeholder mark in the top-left
header with the real logos:

| File | Logo |
| --- | --- |
| `microsoft-logo.svg` | Microsoft logo |
| `microsoft-foundry-logo.svg` | Microsoft Foundry logo |
